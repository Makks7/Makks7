## Selected Projects

**[pH-PINN](https://github.com/Makks7/pH-PINN)** &nbsp;·&nbsp; `PyTorch` `MATLAB/Simulink` `NMPC`  
PINN surrogate for the Henson–Seborg pH neutralization benchmark. Closed-loop offset-free NMPC with output disturbance estimation. pH R² = 0.996 open-loop. Handles extreme titration nonlinearity in under 25 ms per step.

**[PINNs-for-isothermal-CSTR](https://github.com/Makks7/PINNs-for-isothermal-CSTR)** &nbsp;·&nbsp; `PyTorch` `SciPy`  
Physics-constrained neural ODE surrogate for isothermal CSTR setpoint tracking. First case study in a multi-reactor PINN-NMPC thesis framework.

**[PINN-gas-lift](https://github.com/Makks7/PINN-gas-lift)** &nbsp;·&nbsp; `Julia` `Flux.jl` `DifferentialEquations.jl`  
Gas-lift allocation optimizer for Niger Delta wells. 13.4% gas injection savings — presented at SPE STSE 2026 (top 10 of 22 papers).
